# GRAND THEFT PYTHON 3D

## Управление
| Действие | Клавиша |
|---|---|
| Ходьба / бег | WASD / Shift |
| Прыжок | Пробел |
| Стрельба | ЛКМ (J / Enter тоже работают) |
| Прицеливание | ПКМ (зум, точнее, медленнее ходьба) |
| Смена оружия | 1 Пистолет, 2 ПП, 3 Дробовик, 4 Граната, или колесо мыши |
| Перезарядка | R |
| Быстрая граната | G |
| Сесть/выйти из машины | F |
| Камера | мышь / стрелки, C - за спину, M - отпустить мышь |
| Выход | Esc |

Патроны выпадают из убитых полицейских (оранжевые коробки).

## Как собрать .exe через GitHub
1. Создай репозиторий на github.com (кнопка New).
2. Загрузи в него ВСЕ файлы из этой папки, сохранив структуру
   (`main.py`, `requirements.txt`, `.gitignore`, `.github/workflows/build.yml`).
   Папку `.github` можно перетащить в окно браузера целиком.
3. Открой вкладку **Actions**. Сборка запустится сама после коммита
   (или нажми **Build EXE -> Run workflow**).
4. Через 5-10 минут открой завершённый запуск, внизу в **Artifacts** скачай
   `GrandTheftPython3D-windows`, внутри лежит `GrandTheftPython3D.exe`.

Если .exe не запускается, убери `--windowed` в `build.yml`, тогда откроется консоль с текстом ошибки.

## Запуск без сборки
    pip install -r requirements.txt
    python main.py
